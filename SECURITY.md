# Relatar uma vulnerabilidade

Não publique tokens, senhas, conversas ou arquivos reais de configuração em
issues. Para um problema que possa expor credenciais, use a opção de relato
privado na aba Security do GitHub, quando disponível, ou entre em contato com
o mantenedor pelo perfil público antes de compartilhar detalhes sensíveis.

O gerenciador executa o backend local por argumentos separados, mantém os
perfis em diretórios próprios e não lê o conteúdo dos arquivos de autenticação.
O backend incluído no build é fixado por versão e validado por SHA-256.

Remover ou arquivar uma conta pela interface não deve apagar suas credenciais
ou conversas. Problemas que violem essa propriedade merecem prioridade.

A versão inicial é beta. Assinatura Developer ID e notarização Apple não estão
configuradas nesta distribuição.
